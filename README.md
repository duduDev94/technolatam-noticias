# TECHNOLATAM

Portal editorial tecnológico para Latinoamérica.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- JSON
- GitHub Pages

## Publicaciones
Las publicaciones se administran en `data/articles.json`.

Cada artículo utiliza esta estructura:

{
  "id": "identificador-unico",
  "title": "Título del artículo",
  "category": "Innovación",
  "excerpt": "Resumen breve.",
  "content": "Texto completo del artículo.",
  "author": "Redacción TECHNOLATAM",
  "date": "2026-11-17",
  "image": ""
}

Las noticias deben ser originales, verificadas y contar con fuentes. No se deben copiar artículos protegidos por derechos de autor.

## Publicación
El proyecto está preparado para GitHub Pages.
